# 06_phone_reader iPhone で圧力計を読む

iPhone の Safari に計器を写し、画面の緑の円に黒い縁を合わせて「読む」を押すと、圧力の値が出ます。
読み取りは PC で行います(05_ml の net_phone_v1 と同じ処理)。iPhone にアプリは入れません。

## 使い方
1. iPhone_capture を一度使って、iPhone に証明書(iPhone Capture Local CA)を信頼させておく(iphone_capture の README の手順)
2. `start_phone_reader.bat` を実行 → PC のブラウザに QR が出る
3. iPhone のカメラで QR を読む → 「カメラ開始」→ 計器の黒い縁(文字盤との境目)を緑の円に合わせて「読む」
4. 0.25秒おきに3枚撮って読む。自信が下限以上の画像が2枚以上あり、その値の幅が 0.02MPa 以内なら中央値を表示。
   そろわないときは「未取得」と理由を表示。下に3枚それぞれの値(自信)、縁を検出したか が出る。右上の小さい画像は PC が実際に使った範囲と楕円(緑=縁を検出、橙=円の枠をそのまま使用)

- 自信 0.9 未満は「未取得」(--cf で変更。0.8 では針の取り違えが自信0.83で通った例があった)。結果と画像は `results\<日付>\` に保存(results.csv)
- PC の案内ページ(http://127.0.0.1:8766/)に最近の読み取りが並ぶ
- iphone_capture と同時に起動できる(ポートが違う: iPhone 用 https 8444、PC 用 8766)。iphone_capture 本体は変更していない

## 誤差の測定(疑似圧力計を使う)
1. run_wander.bat など COM8 を使っているものを閉じる
2. `run_measure_phone.bat` を実行(針を 0.2 → 0.5 → 0.8 MPa の順に止め、「読む」10回ごとに次へ動かす)
3. iPhone を三脚で固定し、画面下の「姿勢」を選んで(正面・左30 など)「自動で続けて読む」
   → 起動時に原点復帰してから 0.2 へ。10回読むごとに次の値へ動き、移動中は自動で待つ。3値が終わると止まる
4. 姿勢を変えたら「最初から」(原点復帰して 0.2 から)→ もう一度「自動で続けて読む」
   - 針が動かないなどのエラーは iPhone の画面と PC の黒い画面に出る
5. `python summarize_phone.py`(`--since "2026-11-22 07:00"` でその時刻以降だけ)で、姿勢・値ごとの 値あり率・平均誤差(+は多め)・±2%FS以内 を表示
- 正解は UNO への指令値。疑似針はギアのガタと原点復帰で 1%FS 程度ずれることがある

## うまくいかないとき
- QR の下に「証明書に無いアドレス」と出る: PC の IP が変わった。iphone_capture の start.bat を一度起動すると証明書が作り直される(iPhone 側で入れ直しが必要なこともある)
- iPhone から届かない: Windows ファイアウォールで Python のプライベートネットワークを許可
- 縁が「円の枠を使用」になる: 縁を円にもう少し正確に合わせる。照明の映り込みが縁にかかっていないか確認

## 制限
- モデルは TOKO 0〜1.0MPa(白い文字盤・黒い縁)で学習したもの。目盛りの範囲や文字盤が違う計器は、その計器で学習し直す必要がある
- 斜めは約30°まで(学習の変形の範囲)で確認。強い映り込みは苦手

## 仕組み
- iPhone: 画面の円の位置を映像の座標に直し、円の直径の1.5倍の正方形を切り出して JPEG で送る(最大960画素)
- PC: 黒縁の内側の楕円を探す(05_ml/kuro.py)。案内の円から大きく外れたら円の枠をそのまま使う
  → 中心と長径でそろえた 192x192(05_ml/canvas.py)→ 赤チャンネル 96x96 → CNN → 値と自信
