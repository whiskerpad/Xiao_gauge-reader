# gauge-reader  アナログ圧力計 読み取りプロジェクト

> 経緯・判断・現状・既知の課題は [docs/DEVLOG.md](docs/DEVLOG.md) を参照(AIへの引き継ぎ用メモあり)
> 各コードの用途と使い方は [docs/GUIDE.md](docs/GUIDE.md)、カメラを付け直したときの補正は [docs/ALIGNMENT.md](docs/ALIGNMENT.md)

疑似メーター(実ゲージの文字盤+28BYJ-48駆動の指針)を自動で動かし、
角度ラベル付き画像を自動収集して、直読み → 各マイコン比較 → 機械学習 まで進める。

## 進め方
1. 第1段階: XIAO ESP32S3 Sense 単体で針を読み切れるか検証(司令塔はPC)
2. 第2段階: ESP-EYE / Maix Bit など各デバイスで同じ検証を行い比較
3. 第3段階: 機械学習
4. 最終段階: ラズパイを収集サーバーとして導入

## 第1段階の構成
```
            USBシリアル                       Wi-Fi(HTTP)  
 UNO + ULN2003  <──────>      PC       <──────>  XIAO ESP32S3 Sense
 (針を指定値へ移動)       (統括・記録・評価)       (撮影+針角度検出を単体で実行)
```
1. PC → UNO: `MPA 0.35` → 移動・静止待ち後 `OK MOVE ...` が返る(真値)
2. PC → XIAO: 読み取り指令 → XIAOが算出した角度・圧力値を返す
3. PC: 真値と読み取り値の差をCSVに記録。誤差の大きい条件では画像も保存
4. 値・照明・振動条件を変えて繰り返し、誤差分布を評価する

## 01 配線(UNO)
| UNO | ULN2003 |
|---|---|
| D8  | IN1 |
| D9  | IN2 |
| D10 | IN3 |
| D11 | IN4 |
| GND | − (GND) |
| 5V外部電源 | + (5V) ※UNOの5Vピンからも可だが、外部5V推奨。GNDは共通 |

## 01 シリアル指令(115200bps)
`HOME` / `DEG <角度>` / `MPA <圧力>` / `STEP <n>` / `POS` / `ZERO` / `FULL` / `SWEEP <刻み>` / `OFF` / `?`
すべての指令は `OK ...` か `ERR ...` を1行返す。移動系は静止待ち後に返る。

## 01 立ち上げ手順
1. `needle_stepper.ino` をUNOへ書き込む(Arduino IDE)
2. シリアルモニタ(115200, 改行あり)で `HOME` → 針がストッパーへ戻り0付近へ移動することを確認
   - 目盛りが増える方向と逆に回る場合は `INVERT_DIR = true`
3. `pip install pyserial` 後、`python needle_test.py COM5 calib` で校正
   - 表示された `ZERO_OFFSET_STEPS` と `fullSteps` を .ino へ転記して再書き込み
4. `python needle_test.py COM5 sweep` / `random 20` で再現性確認
   - 同じ値で針位置がずれる場合: `BACKLASH_STEPS` を増やす、`STEP_US_MOVE` を増やす(脱調対策)

## 設計メモ
- 原点: 0目盛りのストッパーへ低速で押し当てて原点化(28BYJ-48は位置検出なし)
- ガタ取り: 最終の寄せ方向を常に「減少方向」に統一し、ギアのバックラッシュ誤差を一定化
- 角度⇔圧力: 0〜1.0MPa / 270° の線形換算

## 02 XIAO ESP32S3 Sense 単体読み取り(02_xiao_reader)
- 開発環境: PlatformIO(VS Code)。`include/secrets.h.example` を `include/secrets.h` にコピーし、SSID/パスワードを記入して書き込み(secrets.h は公開リポジトリから除外)
- カメラ: VGA 640x480 グレースケール。読み取り時は古いフレームを2枚捨ててから撮影
- 処理: 円環走査(0.5°刻み)→ 最暗区間の重心角度 → 圧力換算。ESP32内で完結
- 起動後シリアルにIPを表示。`http://gauge-xiao.local/` でも接続可

### API
| URL | 内容 |
|---|---|
| `/` | 設定画面(ボタン選択→画像クリックで中心・内半径・外半径・0目盛り・最大目盛りを設定→保存) |
| `/read?n=3` | n枚解析し中央値をJSONで返す(value, angle, width, contrast, analyze_us 等) |
| `/nn?n=3` | 機械学習(極座標CNN)で n枚読み、JSONで返す(value, conf, ok, ncc, dx, dy, hom 等) |
| `/hom` | カメラ位置の補正(射影変換)の状態。`?m=…` で設定・`?clear=1` で解除(docs/ALIGNMENT.md) |
| `/capture.jpg` | 最新フレーム |
| `/last.jpg` | 直近の /read で解析したフレーム |
| `/config` `/config/set?...` | 設定の取得・変更(NVSに保存、再起動後も保持) |
| `/profile` | 直近の角度-輝度プロファイル・背景・暗さ(記事のグラフ用) |
| `/bg/reset` `/bg/add?n=2` `/bg/save` `/bg/clear` `/bg` | 背景の記録開始・取り込み・保存・削除・状態 |

### 露出の固定
- 設定画面「露出」: 自動のチェックを外し、露光量・ゲインを入れて「適用」→ 再撮影で確認(範囲はセンサー別に画面に表示。OV3660: 露光量0-1536、ゲイン0-64)
- 使用カメラ: OV3660(リボンに刻印。2026-11-13確認)
- 目安: グラフ上部の「白飛び」が0%、「輝度最大」が200〜230程度。ゲインは低いほどノイズが少ない
- 露出を変更すると背景は削除される(記録し直す)

### 背景差分(数字・目盛り線・赤針などの固定物を除去)
1. ブラウザで中心・半径・目盛り角を設定して「設定保存」
2. `python record_background.py --port COM4 --xiao http://<IP>`
   (針を0→1.0MPaへ0.05刻みで動かし、針の前後±15°を除いたフレームの平均=針のない文字盤を記録してXIAOに保存)
3. 以後の /read は背景との差で針を検出(結果JSONの `"bg":true`)
- 中心・半径・目盛り角を変更すると背景は自動削除。カメラ位置・照明を変えたら記録し直す
- 手動でも可: 画面の「背景 リセット」→ 針を動かし、針位置(MPa)を入力して「追加」を繰り返す →「保存」
- 画面下のグラフ: 灰=輝度、緑=背景、赤=暗さ、黄=検出角

### マーカーモード(背景なし・フード不要、2026-11-15〜)
- 計器の外縁(外形φ115と文字盤φ95の間)に黒丸4点のリングを貼る: `docs/marker_ring_115_95.pdf` を100%で印刷して切り抜く
- 毎フレーム4点を検出して射影変換を求め、文字盤平面[mm]の座標で走査する。カメラが斜め・多少ずれても読める
- 設定手順(ブラウザ)
  1. 「マーカー 有効」にチェック → M上/M右/M下/M左 を選んで画像の黒丸をそれぞれクリック → 設定保存
  2. 「マーカー検出」→ 4点に緑の十字、「検出OK」を確認
  3. 「中心」で針の軸、「0目盛り」「最大目盛り」で目盛りをクリック(文字盤平面[mm]・角度に変換される)。中心は矢印キーで0.1mm(Shiftで0.5mm)調整 → 設定保存
  4. 帯[mm]は初期値 19-26 / 27-33 / 34-38(文字盤半径47.5mm)。画像の3色の円が 文字/数字/目盛りの内側 に来ているか確認
- 露出は現場では「自動」を推奨(解析は1枚ごとの相対的な暗さなので明るさの変化に強い)
- マーカーが見えない(手・影・反射)ときは値を出さない(`mk_ok:0`)
- マーカー4点の自動探索(2026-11-17〜): 起動時に保存済みの位置で見つからなければ画像全体から探して初期位置を更新する。
  定期読み取りで3回続けて見つからないときも実行(60秒に1回まで)。設定画面の「自動探索」ボタン、`/mk/find` でも実行できる。
  条件: 計器(マーカー円)が画像の高さの半分程度以上に写り、4点とも縁から離れていること。暗すぎると見つからない(手動でクリック)

#### リング方式と置針の除外(2026-11-16〜)
- **リング方式**(「リング方式」にチェック、初期値 半径18〜38mm・割合0.3): 半径1mm幅のリングを20本取り、
  リングごとに 暗さ→ハイパス、角度ごとに暗さを小さい順に並べて下から3割の値を使う(=リングの7割以上で暗い角度だけが残る)。
  針は軸から先端まで続く線なので残り、文字・数字・目盛り線(一部のリングにしか無い)は落ちる。帯1〜3の設定は使わない。
  画面には半径の内外2本の水色の円が出る
- **置針の除外**(「置針を除外」にチェック、位置=目盛り値、幅±3°): 赤い置針など動かない針の角度を候補から外す(画面に橙の破線2本)。
  針が置針から離れているときに、置針の位置の暗さを学習する(画面の「置針の暗さ(学習値)」)。
  針が置針に重なったときは、置針の位置が学習値の1.6倍以上暗いときだけ値を出し、それ以外は読み取り失敗にする(誤読より失敗を優先)。
  起動直後・設定変更直後は未学習なので、針が置針の上にあるときは値が出ない
- 置針の位置は 0目盛り・最大目盛りと同じく文字盤平面の角度で決まる。破線の間に赤針が入るように位置を調整する
- リング方式は帯3本より処理が重い(リング20本分)。`analyze_us` を確認すること

### 多帯モード(背景なし・現場向け)
- 設定画面「多帯(背景なし)」で有効にし、帯1〜3の半径とハイパス幅を入れて「設定保存」
  - 帯1(内側): 文字の外〜数字の内側、帯2(中間): 数字の付近、帯3(外側): 数字の外〜目盛り線の内端/針先の内側 が目安
  - 針はどの帯でも暗く写るが、文字・数字・目盛り線・針のおしりは一部の帯にしか無い → 全帯の最小値で針だけ残す
  - ハイパス±hpw°: 照明むら等の幅の広い変化を除去。振動でぶれた針より広くする
- 有効時は内半径/外半径と背景は使わない。run_eval.py は背景チェックをせずに測定する
- PCで事前検証: `python offline_eval.py ..\dataset\xiao_s3\<dir> --bands 50-70,75-95,100-112 --hpw 8`

### 設定画面の操作
- 矢印キーで中心を1px移動(Shift併用で5px)。内半径/外半径を選択中は↑↓で半径を変更
- 変更後は「設定保存」

### 設定のコツ
- 内半径: 針のおしり(意匠部分)の先端より外側。おしりは針と180°反対にあり、走査範囲に入ると180°ずれて誤読する
- 外半径: 目盛り線・数字より内側
- 合否判定: 針の暗さ8%以上、かつ「針の前後6°以外の最大の暗さ」の1.5倍以上(snr≥1.5)。区別できないときは値を出さない
- 針が主目盛り線(背景にも写っている)に重なる位置では、snrが下がって失敗しやすい

## 03 PC統括・精度評価(03_pc_runner)
```
pip install pyserial requests matplotlib
python run_eval.py --port COM5 --xiao http://gauge-xiao.local --mode grid --step 0.05 --tag led_on
python run_eval.py --port COM5 --xiao http://gauge-xiao.local --mode random --count 100 --tag led_on
python plot_result.py ..\dataset\xiao_s3\<日時_tag>\result.csv
```
- 結果: `dataset/xiao_s3/<日時_tag>/` に result.csv、summary.txt(平均誤差・RMSE・±1%FS以内率)、
  誤差が `--err-th` を超えた条件の画像とプロファイル
- 背景が無効なときは `run_eval.py` は開始前に中止する(測定中に無効になった場合も中止)。背景なしで測る場合のみ `--no-bg` を付ける
- 直線補正: `python fit_correction.py <result.csv>` で 指示値 = a×生値 + b を算出、`--apply --xiao http://<IP>` でXIAOへ書き込み(背景は消えない)
- `--save-all` で全画像を保存 → 第3段階(機械学習)の学習データになる(ファイル名に真値)

## 取扱注意: XIAO ESP32S3 Sense のコネクタ
本体⇔Sense拡張ボード、拡張ボード⇔カメラ の2か所は極小の基板間コネクタ(押し込み式)。
抜き差しに弱く、2〜3回の着脱でカメラを認識しなくなった事例あり(2026-11-13、2台中1台は回復せず)。

- 症状: シリアルに `Camera probe failed with error 0x105 (ESP_ERR_NOT_FOUND)`
  (PSRAMは正常に認識される。カメラとの通信が成立していない状態)
- 一度動作したら拡張ボード・カメラは外さない。固定はケースや台座ごと行う
- 着脱する場合: 電源(USB)を抜く → 位置を合わせて真上から均等に押し込む → 外すときはこじらず真上へ
- 付け直した後はRESETではなくUSB抜き差しで起動する(カメラは電源投入時に初期化)
- 認識しない場合の切り分け
  1. コネクタを押さえながらUSBを挿して起動 → 認識すれば接触圧不足。テープ/スポンジ/ケースで押さえて固定
  2. Arduino IDE公式サンプル CameraWebServer(CAMERA_MODEL_XIAO_ESP32S3、PSRAM: OPI)でも同じエラーならハードウェア不良
- 実績: 拡張ボードを押し込み直して回復した個体で検証を継続中

## 書き込み・シリアルの注意(XIAO ESP32S3)
- USBが本体内蔵のため、RESETや書き込み開始時にUSBが切断され、COM番号が変わることがある
- 書き込みに失敗する場合: BOOTボタンを押したままUSBを挿す → ポートを選び直して書き込み → 完了後USB抜き差し
- VS Codeの「シリアル モニター」タブでは出力を拾えないことがある。Arduino IDEのシリアルモニタ(115200bps)で確認
- 書き込み前に全てのシリアルモニタを閉じる(ポート占有で失敗する)
