# 05_ml 機械学習用データセット

XIAO ESP32S3 Sense(カメラ正面固定、マーカーなし)で、針の位置と画像の組を自動で集める。
PCだけで動かす(ラズパイは使わない)。XIAOのファームは変更不要(既存の /capture.jpg を使う)。

## 手順
1. UNO(COM8)とXIAO(192.168.11.5)をつなぐ。COM番号・IPが違えば .bat を書き換える
2. `run_check.bat` → `data\check.jpg` で構図(計器全体が写り、ピントが合っているか)を確認
3. `run_collect.bat` → 2000位置を収集(1位置約3秒、約1.5〜2時間)。中断したら
   `python collect.py --port COM8 --xiao http://192.168.11.5 --count 残り数 --tag front_ceiling --out data\<フォルダ名>` で追記
4. 照明などの条件を変えるときは `--tag` を変えて別フォルダに集める

## 出力 data/<日時>_<tag>/
- images/NNNNNN_F.jpg : 640x480 白黒 JPEG(品質80)
- labels.csv : idx, file, mpa(正解), deg, steps, frame, time, move_s, cap_s, bytes, tag
- info_NNNNNN.json : 収集条件、XIAO の /cam・/config

## 注意
- 正解は UNO の指令位置。MPA指令は最終の寄せを常に減少側で行うので、ガタの影響は一定方向
- 300位置ごとに原点復帰して脱調の蓄積を防ぐ(--rehome)
- 収集中は XIAO の定期読み取りが自動で止まる(/capture.jpg へのアクセスから60秒間)
- カメラ・計器を動かしたら別のデータセットとして扱う(切り抜き位置が変わる)
- data/ は .gitignore で GitHub に上げない

## iPhone での収集(collect_iphone.py)
G:\iphone_capture の仕組み(PCからiPhoneに撮影を指示)を使う。iphone_capture 本体は変更しない。

1. XIAO側の収集(run_collect.bat)が終わっていること(UNOのCOMポートを同時に使えない)
2. G:\iphone_capture\start.bat を起動 → iPhoneで撮影ページを開き「カメラを開始」
   - iPhoneは給電し、自動ロックを「なし」に。撮影ページを前面に出したままにする
3. `run_check_iphone.bat` → `data\check_iphone.jpg` で構図確認
4. `run_collect_iphone.bat` → 姿勢ごとに止まるので、iPhoneを置き直してメモ(例: 斜め右30cm)を入力して Enter
   - 既定は 5姿勢 × 200位置、XIAOも同時に撮影(同じ針位置の組データ)。1位置 約3〜4秒(未計測)
   - 中断したら `--out data\<フォルダ名> --pose-start <次の姿勢番号>` で追記
- 出力: images/NNNNNN_ip.jpg(iPhone)、NNNNNN_xi.jpg(XIAO)、labels.csv(cam, pose, pose_note 列あり)、poses.csv
- 姿勢の例: 正面30cm / 正面60cm(遠め) / 斜め左30° / 斜め右45° / 上から見下ろし / 少し傾ける
- iPhoneの画像は iphone_capture の captures\ にも残る。収集後に不要なら削除してよい

## 学習とXIAOでの読み取り(2026-11-19 v1)

## 画像を人工的に斜めにして学習データを増やす(augment_dataset.py)
正面から撮った画像を「斜めから見た形」に変形して、学習データを増やす。針の位置(正解の値)は変形しても変わらないので、元の1枚から何枚でも作れる。
斜め15°・30°の実機テストで落ちた読み取りを、この変形を混ぜて学習することで ±2%FS 以内 9割超まで戻した(train_persp.py は学習中に同じ変形をその場で行う。こちらはファイルとして書き出す版)。

使い方:
1. `pip install numpy opencv-python`(Python 3.9 以上)
2. `run_augment.bat data\20261119_074420_front_ceiling 5` または
   `python augment_dataset.py data\20261119_074420_front_ceiling data\front_aug --count 5`
3. 出力フォルダの `images/` と `labels.csv`(file, mpa, src, tilt, phi, rot, scale)を、元のデータと同じ形で学習に使う

主なオプション:
| オプション | 既定 | 内容 |
|---|---|---|
| --count | 5 | 元の画像1枚から作る枚数 |
| --tilt | 35 | 文字盤の面を傾ける最大角度[度]。向き(phi)は乱数 |
| --tilt-prob | 0.85 | 傾けた画像にする割合(残りは回転・拡大だけ) |
| --rot / --scale / --shift | 8 / 0.15 / 0.05 | 回転[度]、拡大縮小の幅、平行移動(画像幅に対する割合) |
| --center x,y | 画像の中心 | 傾ける中心。文字盤の中心を指定すると文字盤が画面から外れにくい(XIAO正面なら 296,219) |
| --no-photo | なし | 明るさ・コントラスト・映り込み・ぼけ・ノイズを付けない |
| --gray | なし | 白黒で保存 |
| --seed | 0 | 乱数の種。同じ値なら同じ結果 |

注意:
- 変形の中心を文字盤から大きく外すと、傾けたときに文字盤が画面の外へ出ることがある
- 傾きの大きい画像ばかりにすると、正面の精度が落ちることがある(未検証)。元のデータと混ぜて使う
- 他の計器でも labels.csv(file と mpa の列)があればそのまま使える。mpa 列は単位が違っても数値ならよい

## はじめて試す人向けの手順(2026-11-21 追記)
カメラを付け直したら(学習時と位置が違うと読めません)、../docs/ALIGNMENT.md の手順で補正してください。
Windows の PC で、上から順に。コマンドは 05_ml フォルダでコマンドプロンプトを開いて打つ(エクスプローラーのアドレス欄に cmd と打って Enter)。

### 0. 準備
- Python 3.10 以上(python.org から。インストール時に「Add python.exe to PATH」にチェック)
- `pip install numpy opencv-python pillow torch pyserial requests flask`(torch は CPU 版でよい)
- XIAO ESP32S3 Sense に 02_xiao_reader のファームを書き込み済み(VS Code + PlatformIO。Wi-Fi は include\secrets.h)
- 学習データを自分で集める場合は、疑似圧力計(01_stepper_needle、Arduino UNO + ステッピングモーター)も必要
- COM番号と XIAO の IP は、.bat の中の `COM8` と `192.168.11.5` を自分の環境に書き換える

### 1. 画像を集める(疑似圧力計がある場合)
1. `run_check.bat` → `data\check.jpg` で計器全体が写っているか確認
2. `run_collect.bat`(2000位置、約2〜3時間)。照明を変えたセットも集めるなら run_collect_dark.bat などを使う

### 2. 極座標CNN を学習して XIAO に載せる
1. カメラ位置や計器が作者と違う場合: 1枚の画像をペイントで開き、針の軸・0目盛りの先・最大目盛りの先の画素位置を読んで
   `python calib_angles.py --pivot 296,220 --zero 214,309 --full 384,307`
   → 出た CX, CY を polar.py に、A0, SPAN を train_polar.py に書き換える
2. `run_train_polar.bat data\<集めたフォルダ>`
   (中身: make_npz.py ref → make_npz.py polar → train_polar.py → export_polar.py。60エポックで数分〜十数分)
   - include\nn_polar_data.h が上書きされる。元のファイルは nn_polar_data.h.bak に残る
3. VS Code で 02_xiao_reader をビルドして書き込み
4. `run_eval_nn.bat` → 新しい乱数位置50点で採点(results\ に画像と summary.txt)
- 照明を変えたセットも使う: `python make_npz.py polar data\<フォルダ> --name dark` のように dark / desk / window を作り、
  `python train_polar.py --train front dark desk window --out models\my_polar.pt`

### 3. トレンドグラフ
1. `..\04_pi_server\run_server_nn.bat`(PC で Flask。ブラウザで http://127.0.0.1:5000)
2. `..\01_stepper_needle\run_wander.bat`(疑似針をランダムに動かし、指令値もグラフに出す)

### 4. 疑似圧力計がない場合: スマホ写真で試す
- `python read_phone.py <写真フォルダ>` → 値と自信。モデル models\net_phone_v1.pt は 0〜1.0MPa・白い文字盤・黒い縁の計器で学習したもの
- 写真は計器を中央に大きく(画像の8割程度)。縁の検出は画像の中心付近の白から外へ探す
- 文字盤の作り(目盛りの角度・範囲)が違う計器では、そのままでは正しく読めない

### 5. 斜めに強いモデル(PC のみ)とデータの水増し
- `python make_npz.py persp data\<フォルダ> --name front` → `python train_persp.py --epochs 200 --out models\my_persp.pt`
- `python make_npz.py canvas ...`(XIAO・iPhone・写真)→ `python train_phone.py --out models\my_phone.pt`。使い方は make_npz.py の先頭
- train_persp.py / train_phone.py は学習中に斜め変形を自動で加える。変形した画像をファイルとして欲しいとき
  (他の学習ツールで使う、どんな画像になるか見る)は augment_dataset.py(上の節)
